# nbody_ML

Generate Plummer star clusters using REBOUND.

## Linux

```bash
./run.sh
```

## NixOS

```bash
./nixrun.sh
```

Arguments:

```text
--stars
--simulations
--workers
--output
```

Example:

```bash
./run.sh --stars 1024 --simulations 100 --workers 8 --output clusters
```
